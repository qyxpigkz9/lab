# Kubernetes Debug Notes

Quick way to see recent pod events and container exit codes:

```bash
kubectl get pod -n <ns> <pod> -o yaml
kubectl describe pod -n <ns> <pod>
kubectl logs -n <ns> <pod> --previous
```

Useful one-liner to show last state:

```bash
kubectl get pod -A -o jsonpath='{range .items[*]}{"\n"}{.metadata.name}{"\t"}{.status.containerStatuses[*].lastState.terminated.exitCode}{"\n"}{end}' | grep -v '^\s*$'
```

Remember: always check `lastState.terminated.reason` first.
